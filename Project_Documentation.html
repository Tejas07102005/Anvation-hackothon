1. Executive Summary & Overview

EcoCity AI is an end-to-end autonomous waste management solution designed for modern smart cities. Built with a FastAPI Python backend and a responsive React/Vite frontend, the system combines real-time IoT bin telemetry, Bayesian risk calculations, and an autonomous multi-agent AI copilot (EcoAgent) to solve urban waste overflows, optimize truck routes, and prevent landfill exhaustion.

4. Technical Stack & Backend Integration

The application features automated fallback mechanisms for 100% operational uptime:

  • FastAPI Python API (Port 8000): Native endpoints for live agent execution, telemetry sync, and sector metrics.
  • Vite / React Frontend (Port 5174): Minimal, responsive light design with i18n multi-language support (English & Hindi).
  • Fallback Resilience: Centralized API client in src/services/api.js gracefully switches to local simulation if the backend is offline.
